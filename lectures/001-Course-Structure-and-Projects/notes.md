# 001 — Course Structure and Projects

## الفكرة
فيديو ترحيب. جوناس بيوريني الكورس متقسم إزاي والمشاريع اللي هنعملها، عشان أبقى عارف أنا داخل على إيه.

## أهم الحاجات
### حجم الكورس
- حوالي 20 سيكشن، وأكتر من 60 ساعة فيديو.

### الكورس ماشي إزاي
- **سيكشن 2 و3:** أساسيات JavaScript من الصفر. دي الأساس لكل اللي بعده.
- **بعدهم:** developer skills، زي problem solving وإصلاح الـ errors وتجهيز الـ development environment.
- **أول مشروع بـ UI:** سيكشن الـ DOM manipulation، وفيه 3 applications بسيطة.
- **سيكشن 8:** JavaScript بتشتغل إزاي behind the scenes. جوناس بيقول دي معلومات ناس كتير معندهاش.
- **سيكشن 9 و10:** fundamentals تاني بس modern (ES6)، زي maps وdestructuring وstrings وfunctions وclosures.
- **سيكشن 11 و12:** مشروع بيعلّم array methods وnumbers وdates وtimers.
- **بعدها:** website مليان effects، زي lazy image loading وtabbed component وslider.
- **سيكشن 14:** OOP، يعني constructor functions وES6 classes.
- **السيكشن اللي بعده:** مشروع real world فيه OOP + map + إزاي أخطط وأبني structure للمشروع.
- **بعدها:** asynchronous JavaScript، زي إني أجيب data من servers بـ AJAX.
- **سيكشن 17 و18:** الأدوات الحديثة، زي NPM وBabel وParcel وES6 modules، وأكبر مشروع في الكورس.
- **سيكشن 19:** نعمل deploy للمشروع على النت بـ Netlify وGit.

### أعمل إيه بعد الفيديو ده
- أتفرج على المحاضرة اللي بعدها، لأنها مهمة (إزاي آخد الكورس وإزاي أسأل).
- لو أنا عارف الأساسيات، أروح لسيكشن «How to Navigate This Course» وأختار learning path.
- لو جديد، أكمّل بالترتيب عادي.

## ملحوظات لنفسي
- الكورس طويل جدًا، فلازم أمشي بخطة ومستعجلش.
- سيكشن 8 (behind the scenes) وسيكشن 9 دول اللي هيفرقوا معايا في الشغل.
- كل كام سيكشن فيه مشروع، يعني هطبّق على طول.
