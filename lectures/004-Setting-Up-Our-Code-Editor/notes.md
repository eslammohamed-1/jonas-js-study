# 004 — Setting Up Our Code Editor

## الفكرة
قبل ما نكتب كود محتاجين code editor. جوناس بيستخدم VS Code وبيظبط فيه كام setting عشان أمشي معاه بسهولة.

## أهم الحاجات
### ليه VS Code
- جوناس شايفه أحسن editor وأشهرهم، وهو مجاني وشغال على كل الأنظمة.
- فيه بدائل زي Atom وBrackets، بس هو بينصح أستخدم نفس الـ editor عشان أتابع بسهولة.

### الـ Theme
- الـ theme هو ألوان الشاشة والكود.
- أقدر أختار theme موجود: الأيقونة اللي تحت ← Color Theme.
- جوناس بيستخدم **Monokai Pro** (من الـ Extensions). هو مدفوع حوالي 10 دولار، بس ينفع يتستخدم ببلاش وكل كام يوم يطلب منك تشتريه.
- بديل قريب منه وموجود أصلًا في VS Code: **Monokai Classic**.

### الـ Settings المهمة
- **Auto Save ← onFocusChange:** أول ما أسيب الـ editor أو أروح لفايل تاني بيعمل save لوحده. ولو مش لاقيها أعمل search على "auto save".
- **Multi Cursor Modifier:** أخليه ctrlCmd أو أسيبه alt. المهم أفتكر اخترت إيه. هنستخدمه بعدين.
- **Word Wrap:** جوناس مشغّله، بس مش مهم.
- **Format On Save:** لازم يبقى **on**. لسه مفيش formatter، بس هننزّل واحد في سيكشن جاي ومحتاج الـ setting دي تبقى شغالة.

### File Icon Theme
- جوناس بيختار **Seti** عشان شكل أيقونات الفايلات يبقى زي عنده.

### المتصفح
- لازم يبقى عندي آخر نسخة من Google Chrome، لأننا هنجرّب الكود عليه.

## غلطات لازم أخلي بالي منها
- لو نسيت أشغّل Format On Save، الـ formatter مش هيشتغل لما ننزّله بعدين.

## ملحوظات لنفسي
- أنا شغال على Antigravity، وده fork من VS Code، فنفس الـ settings موجودة فيه.
- auto save ← onFocusChange، وformat on save ← on. دول الاتنين المهمين.
