# 003 — Watch Before You Start!

## الفكرة
10 نصايح سريعة من جوناس عن إزاي آخد الكورس صح. قصيرة بس مهمة.

## أهم الحاجات
### 1) الكورس لكل المستويات
- فيه ناس أول مرة تبرمج، وناس جاية من لغة تانية، وناس عارفة JS وعاوزة تبقى advanced.
- لو حاسس إنه سهل أو صعب أو بطيء: أعيد المحاضرات، أو أنط لسيكشن أعلى، أو أغيّر الـ playback speed، أو أسأل في الـ Q&A.

### 2) لازم أكتب الكود معاه (code along)
- "you will learn exactly zero JavaScript skills by just sitting and watching".
- حتى لو بكتب نفس اللي بيكتبه بالظبط، المهم إني بكتب.

### 3) أجرّب كل الـ coding challenges
- أعمل اللي أقدر عليه، ولو وقفت كتير أتفرج على الحل.
- لو مجربتش، يبقى ضيّعت نص فرصة التعلّم في الكورس.
- لو معرفتش أحل: عادي جدًا. الحل نفسه مش هو الهدف. أرجع للمحاضرات وأفهمها أحسن وأكمّل.

### 4) آخد نوتس
- على الـ syntax وعلى الـ theory وعلى كل حاجة. "You can't take too many notes".
- كل واحد وليه طريقته، فألاقي طريقتي.

### 5) لو أول مرة أبرمج: متتخضش
- طبيعي جدًا إني مفهمش كل حاجة في الأول. أكمّل وهفهم.
- فكرة "البرمجة مش ليا" ممنوعة هنا. وكل واحد ليه سرعة تعلّم مختلفة.

### 6) في الأول متشغلش بالك بالـ "ليه"
- في أول كام سيكشن مش لازم أفهم ليه الحاجات شغالة كده.
- ومتشغلش بالك بإن الكود يبقى efficient أو fast أو clean. المهم إنه يشتغل. الـ why والـ clean code جايين بعدين.

### 7) السيكشنات مبنية على بعض
- قبل ما أسيب سيكشن أتأكد إني فاهمه: آخد break، وأراجع الكود والنوتس والمشاريع، وأكتب كود بنفسي أتمرن.

### 8) لو عندي error أو سؤال
- أحاول أحله بنفسي الأول، ودي أهم حاجة لتقدّمي.
- بعدين أدوّر في الـ Q&A، غالبًا حد سأل قبلي.
- وبعدين أسأل سؤال جديد: وصف قصير + الكود على codepen.io وأحط اللينك. من غير كود محدش هيعرف يساعدني.

### 9) Mac ولا Windows ولا Linux
- جوناس مسجّل على Mac، بس كله شغال بنفس الطريقة. لو حاجة مش شغالة، فالسبب مش الـ OS.

### 10) أستمتع
- لو اتضايقت، أوقف وأرجع بعدين.

## ملحوظات لنفسي
- الـ code along ده بالظبط اللي اتفقت عليه في طريقة مذاكرتي، فأنا ماشي صح.
- أحاول في الـ challenge الأول قبل الحل، ومن غير AI.
- قبل ما أقفل أي سيكشن: مراجعة للكود والنوتس.
